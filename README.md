Each file will have a specific format that contains

	- Problem Name and ID
	- Rating and Date of Encounter
	- Success in solving the problem (Conveyed via 3 characters)
	- Intuition
	- How to use that intution
	- Code

Note that success on solving the problem will be in 3 parts, success in obtaining the intutuion to solve the problem without aid, success in acting on said intuition to solve the problem, success in coding the solution
